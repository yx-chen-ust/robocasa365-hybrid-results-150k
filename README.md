# RoboCasa365 · QwenPIv3 150k Hybrid Evaluation

Public, static results dashboard for 8 tasks × 5 episodes, comparing StarVLA QwenPIv3 policy only with GPT-6 Astra + policy.

- Hybrid: 27/40 (67.5%).
- Matched policy-only task/seed subset: 19/40 (47.5%).
- Includes 40-case result links, 10 crossover case analyses, Astra assessments and direct video links.
- Original completion statuses, comparison limitations and attribution caveats are preserved in the dashboard.

## Website

https://yx-chen-ust.github.io/robocasa365-hybrid-results-150k/

GitHub Pages publishes the root of the `main` branch. `index.html` is self-contained and also opens locally. Videos and detailed records are served anonymously from the public [ModelScope dataset](https://www.modelscope.cn/datasets/JackAILab/starRoboHarness), pinned to commit `1f903fde0b4113051fe3b0f285bb52e42c701132`.
